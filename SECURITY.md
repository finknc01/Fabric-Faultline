# Security and Confidentiality

This is a public educational/portfolio repository. Use synthetic or sanitized lab data only. Never commit credentials, private keys, real secrets, employer/customer configurations, internal network details, protected screenshots, or personal/customer data.

Evidence must clearly distinguish **measured**, **derived**, **simulated**, and **modeled/reference** results. If a secret is committed, treat it as compromised: rotate/revoke it immediately and remove it from Git history when necessary.

Use normal GitHub issues only for non-sensitive repository problems; never post sensitive information or credentials in an issue.
